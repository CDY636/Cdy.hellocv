# C++四则运算计算器 (Git培训项目)
## 项目简介
Git实践任务。基于C++编写，实现了基础的四则运算功能（加、减、乘、除）
## 项目结构
```text
git_training/
├── .gitignore      # Git忽略规则文件（忽略编译产物和编辑器配置）
├── README.md       # 项目说明文档（本文件）
└── test.cpp        # 计算器核心源代码
```
## 运行方法
编译代码：
```
g++ test.cpp -o test
```

运行程序：
```
./test
```

测试：
依次输入两个操作数和一个运算符，按下回车
